## Morning (8:00 – 11:00 AM) — Update linkedin-profile.md + Copy to LinkedIn

### Step 1 — Open `job-hunt/linkedin-profile.md`

Open this file and update every section. Then go to LinkedIn and paste the content. Do not skip LinkedIn — the goal of today is a live profile update, not a document update.

### Step 2 — Headline (the most important field)

Your headline appears in every search result, every connection request, every comment you make. It must be specific and keyword-rich.

**Bad headlines:**
- "Aspiring Developer" (signals inexperience, no keywords)
- "Open to work" (no information about your skills)
- "Student" (not how recruiters search)

**Good headlines:**
```
Frontend Developer | React · TypeScript · Next.js | Open to Junior Roles
```
or:
```
React Developer | Building with Next.js, TypeScript, Tailwind CSS | Seeking Frontend Roles
```

Rules:
- Include specific technologies (React, TypeScript, Next.js — not "JavaScript frameworks")
- Include "Open to Junior Roles" or "Seeking Frontend Opportunities"
- Max 220 characters
- No emojis in the headline (some ATS parse LinkedIn headlines)

### Step 3 — About Section (3 paragraphs)

LinkedIn's "About" is indexed by search and read by recruiters who click your profile. Write it in first person, professional but human.

**Template — adapt this to your own words:**

```
I'm a frontend developer with 3+ months of intensive React and Next.js training. 
In that time I built and deployed 3 projects: an e-commerce product explorer, an 
analytics dashboard with 4 chart types, and a full-stack Next.js application — each 
with TypeScript, Tailwind CSS, and automated tests.

My stack: React 18, Next.js 15, TypeScript, Zustand, TanStack Query, Tailwind CSS, 
Shadcn/UI, Vitest, and Framer Motion. I understand Server Components vs Client 
Components, can write type-safe code without any types, and have submitted an open 
source PR to [repo name].

I'm actively looking for a junior frontend developer role. If you're building a product 
with React or Next.js and want a developer who ships working code quickly, I'd love to 
connect.
```

**Rules:**
- Paragraph 1: who you are + what you built (specific, not vague)
- Paragraph 2: your technical stack (keywords recruiters search)
- Paragraph 3: what you're looking for (clear call to action)
- Total: under 2000 characters

### Step 4 — Featured Section

The Featured section appears prominently on your profile. Add:
1. **Your portfolio** — "My Frontend Developer Portfolio" → link to your live portfolio URL
2. **Best project** — "Analytics Dashboard" or your strongest project → link to its live URL
3. **A LinkedIn post** — if you've written good posts this week, feature one

To add: click the "+" icon on your profile → "Add a link" → paste URL → add title and description.

### Step 5 — Projects Section

LinkedIn has a "Projects" section under "Add profile section" → "Recommended" → "Projects."

Add all 3 projects:

**Project name:** E-Commerce Product Explorer
**Description:** Full-featured e-commerce browsing app. Search with debounce, category filter, sort — all combinable. Cart and favorites with Zustand persistence. Dark mode. Built with React 18, Zustand, TanStack Query, Tailwind CSS.
**Link:** [your live URL]
**Skills:** React.js, TypeScript, Tailwind CSS, Zustand

Add Dashboard and Next.js project with the same structure.

### Step 6 — Skills Section

Add these exact skills (LinkedIn uses them for search matching):

- React.js
- TypeScript
- JavaScript
- Next.js
- Tailwind CSS
- HTML
- CSS
- Git
- Node.js (if applicable)
- Zustand

Ask 2-3 connections to endorse your top skills after adding them.

## Midday (11:20 AM – 1:30 PM) — Open to Work + Connections

### Enable "Open to Work"

1. Go to your LinkedIn profile
2. Click "Open to" dropdown under your name
3. Select "Finding a new job"
4. Job titles to enter:
   - "Frontend Developer"
   - "Junior Frontend Developer"
   - "React Developer"
   - "Junior React Developer"
5. Location: set to your city + "Remote" + "Hybrid"
6. Start date: "Immediately"
7. Choose: show to "All LinkedIn members" (not just recruiters — this means your posts and comments carry the badge, which increases visibility)

### Send 10+ Connection Requests

Connect with people who are in a position to help — not just other job seekers.

**Who to connect with:**
- Frontend developers at companies you'd like to work at (search "Frontend Developer" + city/company)
- Engineering managers at companies you'd like to work at
- Technical recruiters who post about frontend roles
- People who commented on any of your posts

**What to include in the connection request note:**

```
Hi [Name], I came across your profile while exploring frontend development roles at 
[Company]. I'm a React/Next.js developer actively looking for junior opportunities. 
I'd love to connect and learn about your experience. — Dinesh
```

Keep it under 200 characters (LinkedIn's note limit for free accounts). Personal > generic.

**Do NOT:**
- Send connection requests without a note to anyone you don't know
- Copy-paste the same note to everyone (personalize at least the company name)
- Connect with 50 people in one hour (LinkedIn may flag this as spam)
