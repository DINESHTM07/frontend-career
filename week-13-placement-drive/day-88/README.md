## LinkedIn Post Block (4:30 – 5:30 PM)

**Post a technical explanation today.** Ideas:
- Explain the event loop with a code example
- Walk through how `useEffect` cleanup works with a real bug example
- Explain CSS specificity with a visual example (paste code, not a screenshot)

Write it in plain language. Developers like posts that teach something they can use. 200-400 words. End with: "What would you add? Would love to hear your approach."

This increases your visibility to recruiters and engineers. It also shows you can communicate technical ideas — a skill companies explicitly hire for.
