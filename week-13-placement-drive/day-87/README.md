## The Mock Interview

### Before starting — set one specific goal

Read your two previous debriefs in `interview-vault/mock-interview-log.md`. Find the thing that was still weak in Interview 2. Name it: "Today I will specifically fix [X]."

### During the interview

Same protocol as always:
1. Restate the problem in your own words
2. Ask about edge cases
3. State your approach before writing any code
4. Narrate your thinking out loud throughout
5. Test your solution with an example
6. State time and space complexity
