## Before You Write a Single Line — Study the Complete Version

Open `project-starters/nextjs-complete/` in your editor. Spend 60 minutes studying it. Do not copy code. Read it like a technical document.

### Questions to answer while reading:

**Architecture:**
- What pages exist? List every route.
- How is the layout structured? Where does the header live?
- How is dark mode handled? (ThemeProvider? Where is it placed?)
- How is navigation built? (NavLink active states, mobile menu?)

**Data:**
- Where does data come from? (API routes? External API? Static?)
- What does the data shape look like? (What TypeScript interfaces are defined?)
- How is data fetched — in Server Components, Client Components, or Route Handlers?

**Components:**
- What components are in `components/ui/` vs `components/` root?
- Are there any compound components or context providers?
- How many Client Components are there? What makes each one need `'use client'`?

**Features:**
- What are the 3–5 most impressive features in the complete version?
- Which feature would be hardest to build? Plan it before starting.

Write your answers somewhere (journal, sticky note, README comment). Close the complete version. Build from memory and judgment.

## Midday (11:20 AM – 1:30 PM) — Build the Core Shell

### Step 1 — Root Layout with ThemeProvider

```tsx
// src/app/layout.tsx
import type { Metadata } from 'next'
import './globals.css'
import { ThemeProvider } from '@/components/ThemeProvider'
import Navbar from '@/components/Navbar'

export const metadata: Metadata = {
  title: {
    template: '%s | Project 3',
    default: 'Project 3',
  },
  description: 'A full-stack Next.js application',
}

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en" suppressHydrationWarning>
      <body className="min-h-screen bg-background font-sans antialiased">
        <ThemeProvider attribute="class" defaultTheme="system" enableSystem>
          <div className="relative flex min-h-screen flex-col">
            <Navbar />
            <main className="flex-1">{children}</main>
          </div>
        </ThemeProvider>
      </body>
    </html>
  )
}
```
