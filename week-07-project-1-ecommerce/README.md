# Week 7 — Project 1: E-Commerce Store (Days 41–47)

**Status:** 📋 CURRICULUM PLANNED — Start when you reach this week
**Theme:** Build a complete e-commerce store from architecture to deployment

## The Project
**Stack:** React + TypeScript + Zustand + React Router + Tailwind CSS
**Goal:** A production-quality shopping experience with cart, filtering, and checkout

## Daily Plan

| Day | Focus | Deliverable |
|-----|-------|------------|
| 41 | Project setup + routing architecture | App shell with 4 routes wired up |
| 42 | Product listing — data layer, filtering, search | Filterable, searchable product grid |
| 43 | Product detail page + add to cart | Detail view + cart state in Zustand |
| 44 | Cart — quantity management, persistence, cross-tab sync | Cart persisted to localStorage |
| 45 | Checkout flow — multi-step form with validation | 3-step checkout (shipping → payment → confirm) |
| 46 | Polish — loading skeletons, error states, empty states | Every state handled gracefully |
| 47 | Deploy to Vercel + update portfolio + write README | Live URL in `data/projects.js` |
