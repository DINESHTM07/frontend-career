## ONE-PAGE LAYOUT GUIDE

When building the actual PDF/Word resume, use this order and space allocation:

```
HEADER                   3–4 lines
SUMMARY                  3 lines
TECHNICAL SKILLS         6–7 lines (flat format, not a table)
PROJECTS                 ~24 lines (3 projects × 4 lines each + headers)
EDUCATION                5–6 lines
PUBLICATIONS             3 lines
─────────────────────────
Total target: 50–55 lines → fits on one A4 page at 10–11pt font
```

**Font:** Calibri, Inter, or Georgia · **Size:** 10–11pt body, 13–14pt name
**Margins:** 0.6–0.75 inch all sides
**Colors:** Black body text, one accent color (e.g. `#0ea5e9` brand blue) for section headers only
