# Job Application Tracker

> **How to use:**
> - Add a row every time you apply anywhere — even speculative cold emails
> - Update Status every time something changes
> - Review this every Monday morning (5 min) — anything needing follow-up?
> - Sort by Follow-up Date to see what needs action today

---

## Status Key

| Code | Meaning |
|---|---|
| `Applied` | Submitted — waiting |
| `Contacted` | Cold email / LinkedIn sent — not applied yet |
| `Screening` | HR call scheduled or completed |
| `Technical` | Technical round in progress |
| `Final` | Final round / culture fit |
| `Offer` | Offer received — reviewing / negotiating |
| `Accepted` | Offer accepted |
| `Rejected` | Rejected at any stage |
| `Ghosted` | No response after 2+ follow-ups |
| `Withdrew` | You withdrew from the process |
| `On Hold` | Company paused hiring |

## Weekly Review Checklist

Run this every Monday (takes 5–10 minutes):

```
[ ] Any application older than 7 days with no response? → Send follow-up
[ ] Any technical rounds pending? → Prep for them this week
[ ] Any offers expiring? → Prioritize response
[ ] Any rejections? → Send feedback request email (see follow-up-templates.md)
[ ] Applied to at least 5 new roles last week? → If not, increase volume
[ ] Any companies moved to "Ghosted"? → Archive and move on
```

**Common rejection patterns and fixes:**

| Pattern | Fix |
|---|---|
| Rejected at resume screen | Tailor skills section to job description keywords |
| Rejected after HR screen | Practice "tell me about yourself" — sharpen the story |
| Rejected after technical | Identify the gap — what question went badly? |
| Rejected after final | Usually culture / team fit — hard to predict, keep going |
| Ghosted everywhere | Increase application volume, fix cold email subject lines |
